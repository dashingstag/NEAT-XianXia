# icons-brush — 31 brush-stroke panel icons

24×24 PNGs, single-stroke ink style + cinnabar seal stamp. One icon per
PRODUCTS good, per site type, plus xianxia extras (sword, scroll, lantern,
ingot, lotus, seal).

Integration: `main.gd` inspector titles (BBCode `[img]`), the resource
placement OptionButton, job-board rows. Committed textures — no atlas.
