# terrain-flora-xianxia — tree, patch and discovery glyphs

One PNG per element (64×64): pine/bamboo/willow/plum tree archetypes,
berry/timber/stone/fish patch visuals, herb/mushroom/lotus flora,
spirit-herb (cyan ring), qi mist and undiscovered-site marker.

Integration: `_tree_points` archetype table in `field.gd` and the
patch-kind glyph table; new flora rows await sim-side patch kinds.
