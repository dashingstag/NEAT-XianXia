# Path Network Lab — unified entry point

Single server hosting both footpath experiments over the shared
generated dataset:

- **path cover (min set)** — `/cover/` — the minimum-path-cover lab:
  demand-weighted greedy set cover over real cached trips, daily dawn
  replay with inclination feedback, game-rule baseline, and the
  appeal × radius sweep.
- **trail replay (slime mold)** — `/trail/` — the deposit/decay trail
  lab replayed over recorded walks.

```text
npm start        # http://127.0.0.1:4177
```

Both tabs read `../trail-lab/data` (generated by
`sim/crates/sim-core/examples/trail_lab.rs`). The standalone labs on
`:4175`/`:4176` still work independently.

See `INTEGRATION.md` for the plan to bring the min-cover approach into
`sim-core`.
